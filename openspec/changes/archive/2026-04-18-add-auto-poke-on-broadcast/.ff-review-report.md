Confirmed with existing test `tests/broadcast-auto-poke.test.ts` L122 (retry delays=[30,180,600] assertion, not [30,30,180,180,...]).
4. **No timer leak**: `clearAllRetries()` in test teardown; production retries clean themselves via `retryMap.delete(key)` on success/exhaustion/cancel.
