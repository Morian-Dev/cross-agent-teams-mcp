**Security review of hash implementation**:
- sha256 input is the trimmed Authorization header string (includes `Bearer ` prefix). Plaintext token never stored in memory beyond the per-request `raw` local.
- `sessionOwners` Map holds 64-char hex digests only; no plaintext persistence or log emission.
- Error response body is the literal `{ error: 'agent_id_collision' }` — zero token leakage in 409 payload.
- Hash comparison is plain string equality. Acceptable because both sides are hashes (not secrets); timing attacks on hash equality reveal nothing useful. Design.md §1 explicitly documents this choice.
- No logging of Authorization header or its hash anywhere in the changed code.
